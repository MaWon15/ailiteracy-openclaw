# Chapter 2: Intelligent Agents - Key Excerpts

## 2.1 Agents and Environments

An **agent** is anything that can be viewed as perceiving its environment through sensors and acting upon that environment through actuators.

### Agent Function
The agent function maps from percept sequences to actions:
f: P* → A

Where:
- P is the set of possible percepts
- A is the set of possible actions
- P* is the set of finite percept sequences

### Rational Agent
A rational agent is one that does the right thing - that is, one that chooses actions that are expected to maximize its performance measure, given the evidence provided by the percept sequence and whatever built-in knowledge the agent has.

## 2.2 Good Behavior: The Concept of Rationality

### Performance Measures
- Must be objective and measurable
- Should reflect the designer's goals
- May include multiple criteria

### Rationality vs Omniscience
- Rationality maximizes expected performance
- Omniscience maximizes actual performance
- Rational agents make the best of their limited information

### Information Gathering
- Sometimes the best action is to gather more information
- Trade-off between information gathering and acting
- Depends on cost of information vs value of better decision

## 2.3 The Nature of Environments

### Properties of Task Environments

1. **Fully Observable vs Partially Observable**
   - Fully observable: Agent's sensors give access to complete state
   - Partially observable: Agent lacks full access to state

2. **Single Agent vs Multiagent**
   - Single agent: Only one agent operating
   - Multiagent: Multiple agents operating (competitive or cooperative)

3. **Deterministic vs Stochastic**
   - Deterministic: Next state completely determined by current state and action
   - Stochastic: Next state may be uncertain

4. **Episodic vs Sequential**
   - Episodic: Experience divided into atomic episodes
   - Sequential: Current decision affects future decisions

5. **Static vs Dynamic**
   - Static: Environment doesn't change while agent is thinking
   - Dynamic: Environment changes during deliberation

6. **Discrete vs Continuous**
   - Discrete: Finite number of distinct states/actions
   - Continuous: Infinite states/actions

7. **Known vs Unknown**
   - Known: Agent knows the rules of the environment
   - Unknown: Agent must learn the rules

## 2.4 The Structure of Agents

### Agent Programs
Agent programs implement the agent function, taking percepts as input and returning actions.

### Simple Reflex Agents
- Select actions based only on current percept
- Ignore percept history
- Work only in fully observable environments
- May loop in partially observable environments

### Model-Based Reflex Agents
- Maintain internal state representing unobserved aspects
- Update state based on percepts and actions
- Choose actions based on current state
- Handle partially observable environments

### Goal-Based Agents
- Consider future consequences of actions
- Search for action sequences that achieve goals
- More flexible than reflex agents
- Require goal information and search capability

### Utility-Based Agents
- Consider desirability of different states
- Maximize expected utility rather than just achieving goals
- Handle trade-offs between conflicting goals
- More sophisticated decision making

### Learning Agents
- **Learning element**: Improves performance element
- **Performance element**: Selects actions
- **Critic**: Provides feedback on performance
- **Problem generator**: Suggests exploratory actions

## 2.5 Summary

- Agents interact with environments through sensors and actuators
- Rational agents maximize performance measures
- Environment properties determine appropriate agent designs
- Agent architectures range from simple reflex to learning systems
- Learning agents can improve over time through experience

Key equation: Agent = Architecture + Program

The architecture makes percepts available to the program, runs the program, and feeds actions to the actuators.
