## What is an AI Agent?

An AI agent is a system that:
- **Perceives** its environment through sensors
- **Reasons** about what it perceives
- **Acts** to achieve goals
- **Learns** from experience (in advanced agents)

### Agent Types (from AIMA Chapter 2)
1. **Simple Reflex Agents**: React directly to current perceptions
2. **Model-Based Reflex Agents**: Maintain internal state
3. **Goal-Based Agents**: Consider future consequences
4. **Utility-Based Agents**: Maximize expected utility
5. **Learning Agents**: Improve performance over time

## Agent Environments

### Properties of Task Environments
- **Observable**: Full vs partial observability
- **Deterministic**: Predictable vs stochastic
- **Episodic**: Sequential vs episodic
- **Static**: Environment changes vs stays same
- **Discrete**: Finite vs continuous state space

### Examples
- **Chess**: Fully observable, deterministic, episodic
- **Self-driving car**: Partially observable, stochastic, sequential
- **Discord discussion**: Partially observable, stochastic, sequential

## Agent Architecture

### Basic Components
- **Sensors**: Input from environment
- **Actuators**: Output actions
- **Reasoning Engine**: Decision making
- **Knowledge Base**: Stored information
- **Learning Component**: Adaptation

## Key Takeaways

- Agents are goal-directed systems that interact with environments
- Different environments require different agent architectures
- Agent design involves trade-offs between complexity and performance
- Understanding agent limitations is crucial for responsible AI development
